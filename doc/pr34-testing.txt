Moonshine 3.0.0 Timewarp - Online Prototype 34

Changes
- Online menu opening resolves pending PB ghosts first using the existing save policy.
- Online Stageloader preserves its next IL and the host-selected episode while a PB save/discard prompt is pending.
- Native save boxes count as ready for online starts once CARD is idle. Loads, fades and queued departures still block readiness.
- Successful connections save up to eight named codes. Y opens Saved codes from code entry; A loads the selected code, then Start submits it. Z forgets a code.
- Code keyboard: B deletes, X goes back. Loading a saved code never joins automatically.
- Saved codes persist in the current region's Wii settings when the menu closes. Dolphin retains them for the current game boot, like its existing online preferences.
- Standard package: no custom music or photo.
