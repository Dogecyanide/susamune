# Moonshine Launcher FOXTROT

V2.3.0 プレリリース・コマ送り入力とタイマーの修正

FOXTROT は、動きの確認や走行の比較に使う練習機能を追加します。新しいレベル内スプリットは追加していません。チェックポイントは今後、一つずつ手作業で定義・検証します。

## インストール

ZIP 内の `moonshine_launcher` フォルダーを SD カードの `apps` にコピーします。配布ファイルだけを更新し、既存のテーマ、音楽、`susamune.ini`、記録、ゴーストは残してください。対応する日本・北米・欧州版のディスク、または自分で用意したゲームイメージを使用します。メモリ形式が変更されたため、古いランチャーと FOXTROT の mod ファイルを混在させないでください。

Homebrew Channel から Moonshine Launcher FOXTROT を開きます。**Version** でゲーム版を選び、**Path** で SD・USB の ISO/CISO、または実ディスク用の **Disc Drive** を選びます。**Launch Game** で起動します。Auto Boot が有効な場合は、起動中に B を押し続けるとランチャーのメニューへ戻れます。

起動元のデバイスにアクセスできる場合は、カーネル起動画面より先にテーマを読み込みます。早期に利用できない USB デバイスは、通常のストレージ初期化後に再試行します。音楽はカーネルの準備後に開始します。起動中の文字とエラー表示にも描画状態を明示し、暗いテーマでは縁取りを付けます。

設定や mod の保存データは、ランチャーを起動したデバイスに保存されます。たとえばランチャーが SD、ゲームが USB にある場合も、設定は SD に保存されます。日本・北米・欧州版の設定とボタン割り当てはそれぞれ独立しています。更新時も `susamune_*` の名前は変更しないでください。

## メニュー

標準のメニュー操作は Y + Start です。L/R で上位タブ、C スティックで項目を移動し、A で選択、B で戻ります。

- **Quick**：Shined に登録したお気に入り。
- **Practice**：Frame advance、Free camera、Input replay の個別ページと、ステート、練習ルール、乱数、ゲーム設定。
- **Runs**：IL、プレイリスト・連続成功、記録、PB Safety、タイマー・スプリット設定。
- **Ghosts**：ゴーストとの競走、観察、保存、管理。
- **Display**：表示位置、HUD、タイマー・スプリット、外見。
- **System**：ボタン割り当てと簡易ガイド。

## 練習用一時停止とコマ送り

**Practice > Frame advance** を開きます。選択中の操作には現在のショートカットが表示され、**X** でその場で変更できます。System > Button binds からも変更可能です。

| 標準操作 | 機能 |
|---|---|
| 十字キー下 | 練習用一時停止・再開、停止予約の取り消し |
| 十字キー上 | まず一時停止し、次の入力から一回ずつコマ送り |
| 未設定 | フリーカメラ、入力録画・再生・停止 |

上の表は新しい設定の標準値です。以前の L を使う割り当ても含め、既存の設定は保持します。Z の既存機能も維持します。

ロード中、開始演出中などマリオを操作できない間でも Pause または Step を押して停止を予約できます。**Armed** は、マリオを操作できるようになった瞬間に停止するという意味です。ボタンを押し続ける必要はありません。Pause をもう一度押すと取り消します。待機中に Step を繰り返しても余分なコマ送りは追加しません。

練習用一時停止では、ゲームプレイと QFT が止まります。Step 一回で通常のゲーム一コマ分が進み、QFT もその分だけ進みます。音楽やゲーム内部の時計は動き続けます。この機能を使った試行では、QFT の横に小さな **TAS** を表示します。通常の PB 対象外となるため、新しい試行を始めるにはステージを再開してください。

フリーカメラが **Off** なら、A を押しながら Step を押して、そのコマでジャンプできます。A を押したまま Pause を始めることもでき、他のゲーム用ボタンも Pause・Step と同時に使えます。後のコマでもう一度 A を押したい場合は、A を離してから押し直し、その後 Step を押してください。A を離さなければ、押しっぱなしとして扱います。Pause・Step 用コンボ自体はマリオの操作に使われず、割り当てに L/R が含まれる場合は離すまでトリガー入力も抑えます。メニューから Step または Resume を選んだ場合は、A を離すと進みます。

スピンはメインスティックを自分で操作します。各 Step を押す前に、次の方向へスティックを倒してください。スティックでマリオを操作できるよう、フリーカメラは Off にします。

## フリーカメラ

**Practice > Free camera** で On にすると、通常のゲームプレイを自動で一時停止します。メインスティックで移動、C スティックで視点、L/R のアナログ入力で下降・上昇します。**Movement speed** で0.25～4倍の速度を保存できます。X は一時的な加速です。

メインスティックの左右が逆に感じる場合は、同じページの **Reverse sideways** を On にしてください。左右移動だけを反転し、C スティックの視点操作は変更しません。標準は Off です。Recenter でゲーム本来の視点へ戻せます。フリーカメラを Off にしても一時停止は続くため、再開するには Resume を選びます。

通常の Start ポーズ中にも使用できます。フリーカメラを使いながらコマ送りもできますが、**Camera On の間は Mario input Off** となり、A やスティックはマリオの操作に反映されません。ジャンプやスピンをコマ送りする前に Off にしてください。カメラの変更は一時的な描画状態で、ゲーム処理やステート操作前に復元されます。場面が変わると終了します。

Ghost Watch と Watch2 でも一時停止・コマ送り・フリーカメラを使用できます。一時停止中はゴーストの再生位置も止まります。Watch を再開してもフリーカメラを維持できます。B または Start で Watch を終了します。メニュー用コンボで mod メニューを開いた場合は終了しません。

## 入力の録画と再生

1. 通常のゲームプレイ中にステートを保存します。
2. **Practice > Input replay (experimental) > Record from savestate** を選びます。
3. メニューを閉じ、ボタンを離します。保存したステートを読み直して録画が始まります。
4. 操作を行い、mod メニューを開くと録画が停止し、内容は残ります。同じページの Stop recording or replay に X でショートカットを割り当てることもできます。
5. Replay recorded inputs を選ぶと、同じ開始ステートから入力を再生します。

録画上限は **4096 描画フレーム**です。30 fps で約137秒、25 fps で約164秒です。録画は今回の起動中のメモリにだけ保持します。ステートの上書きや場面変更で無効になります。設定が変わっている場合も再生できません。再生中は B または Start で中止できます。

入力再生は実験的機能です。各フレームでマリオ、乱数、一部カウンターの簡易チェック値を比較し、不一致があると停止します。一致しても敵やエフェクトを含む世界全体の完全な再現は保証しません。このローカル録画は共有用リプレイファイルではありません。

## ゴースト入力とスプリット比較

個人ゴーストとインポートはページ表示になり、45件・12件および合計10時間のライブラリー上限はありません。**Personal page** または **Imported page** を選び、C スティック左右でページを切り替えます。A は次ページです。**Save latest ghost** は新しい個人ファイルを保存します。個人ゴーストの空欄を選んだ場合も、**Save latest ghost** の確認が表示されます。既存のゴーストは引き続き利用でき、Watch2 では別ページから二つ目を選べます。

ライブラリーの容量はストレージの空き容量によって決まります。ゴースト一つの録画上限は従来どおり約15分です。インポートしたファイルは元のフォルダーに残り、削除や読み込みは選択したファイルを対象にします。

新しいゴーストには、その試行で使われた入力と、既存の対応スプリットの時刻を保存できます。以前の位置情報だけのゴーストも読み込めます。入力情報がなければ、利用不可として表示します。

**Ghosts > Ghost inputs** で Off、Ghost、**Both ghosts** を選びます。Display > Layout editor > Controller inputs と、従来の Other HUD にも同じ設定があります。Both ghosts は競走中には自分とゴースト、Watch2 では二つのゴーストの入力を表示します。インポートしたゴーストがマリオを操作する機能ではありません。

練習用一時停止、フリーカメラ、コマ送りを使用したゴーストは **TAS** と表示します。停止していた時間を再生から除くため、カメラ調整や入力の検討中の待ち時間は記録に入りません。練習用一時停止中は QFT も止まります。TAS ゴーストは通常の PB 対象外です。

Display > Timer and splits > Timer and splits の比較対象は **Off → PB → SOB → Ghost** です。SOB は保存済みの各区間ベストの累計です。Ghost は選択した競走相手の互換性のあるスプリット時刻を使います。情報が欠ける場合は `--` と表示し、時刻を推測しません。

同じ設定を Runs > Timer and splits からも開けます。最初のページの **Level splits** が表示のオン・オフです。

共有用に書き出したゴーストは、ランチャーのデバイスの `susamune_ghosts/share/` 以下に保存されます。受け取った `.smsghost` は `susamune_ghosts/import/` に入れ、Ghosts からインポートします。内部保存用の `.sgh` は元のフォルダーに残してください。既存の Full Reds IL は Runs から選べます。秘密コースまでの移動と赤コインをまとめて計測する場合は、フルレベルのルートを選んでください。

## レイアウトと色

Display > Layout editor は、Timers、Controller inputs、Metadata、Native HUD colours、Custom text、Practice feedback、Menu and notifications に分かれています。Rollout と Dust は Practice feedback にあり、HUD and displays > Movement feedback からも編集できます。

**Timers > Sunshine timer** で位置・サイズ・不透明度・明るさ、13文字、TIME/TEMPO、背景の帯を編集します。位置は画面全体に移動できます。

最初の **Appearance** で **Original** または **Custom** を選びます。対象を All にするとタイマー全体に適用し、Start で文字や画像を一つずつ選べます。Original はゲーム本来の色と陰影に戻し、位置・サイズ・保存済みのカスタム RGB は保持します。Custom に戻すと、その RGB を再び使えます。RGB を変更すると、その対象は Custom に切り替わります。**Appearance で Z** を押すと、確認後に Original へ戻ります。タイマー全体の色を戻すには、**All > Appearance > Original** を選んでください。

**Native HUD colours** の Health counter colour と Underwater air colour は独立した色設定です。リセットすると元の色へ戻ります。RGB 編集中に **Y** を押しながら C スティックを操作すると、4ではなく1ずつ調整できます。A で保存、B で破棄、Z で選択項目のリセットを確認します。

**Metadata** では Field gap、Row gap、Fields per row、Value widths を C スティック左右で調整できます。横並びで Fields per row を設定すると、指定した項目数で折り返します。Auto は画面端で折り返します。Stable は桁数が変わっても位置を保ち、Compact は空白を詰めます。文字ごとの色は元の項目に対応したままです。

## Dolphin

対応するゲーム版の BPS パッチをクリーンな ISO に適用します。Wii ランチャーの ZIP は Homebrew Channel 用です。mod の設定を保存するには、スロット B のメモリーカードを有効にしてください。ステート読み込み時に汚れを正しく復元するため、Texture Cache Accuracy を Safe に設定します。更新時は Sunshine 本来のセーブと、スロット B の Moonshine 設定ファイルを残してください。

コマ送り機能には新しい Dolphin リリースを使用してください。同じ FOXTROT イメージで、Dolphin 2606a の JIT と 5.0 の Interpreter は一時停止中のメニュー入力を正しく処理しましたが、5.0 の JIT では入力が止まる場合がありました。

## 不具合の報告

このプレリリースは実機テストが必要です。報告にはゲーム版、ステージ、設定、再現手順、画面に出るビルドチェックサムを添えてください。クラッシュのテキスト、`.bin`、`.core` はまとめて保管してください。`tools/decode_crash.py` は Python 3 でバイナリ報告を読めます。詳細な報告を作れなくても最小情報の保存を試みますが、電源を切った後まで残すにはストレージへの書き込みが必要です。

MEM1 の予約量は V2.2 より256 KiB増えた768 KiBです。固定タイマー領域、モデル用ヒープ、ステートの領域は分離したままです。最も重いステージでの実際の空きメモリも、実機で確認してください。
