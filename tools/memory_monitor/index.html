Measurements approximately twice per second. The private reservation-test build writes and verifies a fixed pattern only inside its guarded, claimed memory areas. Peak observed is the largest sampled usage; brief allocations between samples may be missed. Free space is not automatically safe to reclaim. MEM1 heaps are nested: their usage must not be added together. Ghost figures count pose/input payloads, not the separate camera/model buffers. Capture controls can briefly pause the game and copy bounded allocator metadata. There are no arbitrary-address read/write commands or public web service.
